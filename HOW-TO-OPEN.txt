rocket - how to open it
=======================

Pick the right download
-----------------------
  Windows PC (most laptops)        rocket-windows-amd64.zip
  Windows on ARM                   rocket-windows-arm64.zip
  Mac with Apple chip (M1/M2/M3+)  rocket-darwin-arm64.zip
  Mac with Intel chip              rocket-darwin-amd64.zip
  Linux PC                         rocket-linux-amd64.zip
  Linux on ARM (Raspberry Pi 4/5)  rocket-linux-arm64.zip
  Android phone (8.0 or later)     rocket-android.apk  (see ANDROID below)

Not sure which Mac? Apple menu > About This Mac. "Chip: Apple M..." means
arm64. "Processor: Intel ..." means amd64.

Not sure which Linux? Run: uname -m
"x86_64" means amd64. "aarch64" means arm64.

Check the download (optional): the release page has a SHA256SUMS file.
  Windows:  certutil -hashfile rocket-windows-amd64.zip SHA256
  Mac:      shasum -a 256 rocket-darwin-arm64.zip
  Linux:    sha256sum -c SHA256SUMS --ignore-missing
The long number must match the line for your zip (or the APK).

Run rocket on two or more computers or Android phones on the same network
to send files between them.

Update every device to 1.1: rocket 1.1 cannot send to or receive from
rocket 1.0 (it encrypts transfers with a new protocol). A device that still
runs 1.0 shows "Needs update". Unzip or install 1.1 over 1.0; your
settings, trusted senders and history stay.


WINDOWS
-------
1. Right-click the zip > Extract All. Open the new folder.
2. Double-click rocket.exe.
3. Windows SmartScreen may say "Windows protected your PC" because the
   program is not code-signed. Click "More info", then "Run anyway".
   You only need to do this once per download.
4. Your browser opens to the rocket page. Leave the black window open
   while you use it. Click Quit in the page (or press Ctrl+C in the
   black window) to stop.

The first time you run rocket, Windows Defender Firewall may show a
"Windows Security Alert". rocket needs to be reachable on your local
network so other computers can send you files. Tick "Private networks"
and click "Allow access". Do not allow it on public networks.

Tray icon (optional): double-click rocket-tray.exe. A rocket icon appears
in the notification area (it may be under the ^ arrow). It gets a red
badge when someone is waiting for your answer. Right-click it for Open,
Start and Quit rocket.


MAC
---
1. Double-click the zip to unzip it. Open the new folder.
2. Control-click rocket > Open, then Open again. macOS Gatekeeper warns
   about unsigned programs; this bypasses it once per download.
   If macOS still refuses: System Settings > Privacy & Security, scroll
   down and click "Open Anyway".
3. Your browser opens to the rocket page. A Terminal window stays open
   while rocket runs. Click Quit in the page (or press Ctrl+C in
   Terminal) to stop.
4. If macOS asks whether rocket may "find devices on your local
   network" or accept incoming connections, click Allow.

There is no tray icon for Mac in the zip (see the README to build one).


LINUX
-----
1. Unzip the file:  unzip rocket-linux-amd64.zip -d rocket
2. In a terminal:   cd rocket && ./rocket
   (If it says "permission denied", run: chmod +x rocket rocket-tray)
3. Your browser opens to the rocket page, or open the address printed in
   the terminal. Press Ctrl+C in the terminal to stop.
4. If your firewall is on, open the ports rocket uses, for example with
   ufw:
     sudo ufw allow 29005/tcp
     sudo ufw allow 29006/udp
     sudo ufw allow 5353/udp

Tray icon (optional): run ./rocket-tray & . It needs a desktop with a
system tray (KDE, or GNOME with the AppIndicator extension).

To run without a browser (for example on a Raspberry Pi), use:
  ./rocket recv


ANDROID
-------
rocket for Android is not in the Play Store. You install the APK file
yourself ("sideloading"). It needs Android 8.0 or later.

1. On the phone, open the release page in the browser and tap
   rocket-android.apk to download it.
2. Open the download (tap the notification, or open Files > Downloads
   and tap rocket-android.apk).
3. Android says that for your security the phone is not allowed to
   install unknown apps from this source. Tap Settings, turn on
   "Allow from this source", then go back and tap Install.
   (Android 8 to 14 call it "Install unknown apps"; you can turn it off
   again afterwards in Settings > Apps > Special app access.)
4. Google Play Protect may warn that it does not know the app, or offer
   to scan it first. Scanning is fine: tap "Scan app", then Install. If it
   says "Unsafe app blocked" or "Harmful app blocked", tap "More details"
   and then "Install anyway". rocket is open source and the APK is signed
   with the project's release key; check it against SHA256SUMS if you
   want to be sure it is the real one.
5. Open rocket. Allow notifications when Android 13 or later asks, so
   incoming offers can pop up with Accept and Decline.

To send, pick a computer or phone in the Send tab, then Files or Folder.
You can also Share to rocket from the gallery or any other app.

To receive, turn on "Receive files" in the Receive tab. While it is on, a
notification shows that rocket is listening, also in the background. Turn
it off in the same place.

Files you receive are saved in Download/rocket on the phone.

To update, install the new APK over the old one the same way; your
trusted senders and history stay. Uninstalling removes them, and the
phone gets a new fingerprint when you install again.

If the Wi-Fi drops during a transfer, rocket reconnects by itself and
carries on where it stopped. If it gives up, the send shows "Interrupted"
with Resume for 24 hours.


WHERE DO FILES GO?
------------------
Files other people send you, and files you accept, are saved to your
Downloads/rocket folder. You can pick another folder in Settings. On
Android they go to Download/rocket.


SENDING FROM A PHONE WITHOUT THE APP
------------------------------------
rocket prints a "drop page" address such as http://192.168.1.20:29005/ .
Open it in the phone's browser (same Wi-Fi), tap "Choose files", and
accept the offer on the computer. This works on any phone, including an
iPhone, and on a guest's laptop. Files sent this way are NOT encrypted
(browsers only allow that on HTTPS pages), and an upload cut off by the
network starts over.


IS IT SAFE?
-----------
rocket listens on your local network so other computers can send to it
(on Android only while "Receive files" is on). The first transfer from a
new computer or phone asks you to approve it. Only
approve senders you recognise, and compare the fingerprint before you
choose "Always accept".

The contents of files sent between rocket apps are encrypted. File
names, sizes and device names are not, and neither is the browser drop
page, so someone watching the network could still see what you send.
Use rocket on networks you trust (home, office), not public Wi-Fi. See
the README and the security notes at
github.com/donaldsteele/rocket (docs/security.md).
